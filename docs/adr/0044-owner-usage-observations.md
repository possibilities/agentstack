# 44. Observe registered accounts without routing them

Status: accepted, 2026-09-25. Extends [ADR 0036](0036-account-bound-acp-foundation.md)'s isolated Worker accounts and [ADR 0012](0012-stable-codex-account-ids.md)'s immutable Codex identities.

Extended by [ADR 0060](0060-claude-sdk-workers.md) for read-only usage of isolated Claude Worker accounts. Extended by [ADR 0063](0063-usage-subscription-end-and-sample-age.md) with a subscription period end where a provider exposes one.

The owner starts a required `usage` Package API child. It reads the `auth` Package API's Worker account inventory, including Codex accounts without an ACP binding, and observes each ready Grok/Devin account (including disabled accounts) and each non-removing Codex account under its stable AgentStack ID. It also observes the separately installed, machine-level Grok Bot login. Its only public operation is `usage_snapshot`; the `usage_changed` Event invalidates that snapshot. The operation reports account availability, measurements, last-good time, attempt time, freshness and a bounded error code. No operation chooses an account, changes a credential, claims usage, or tells a caller whether to dispatch a Worker.

The child reads the existing private Codex auth store and native per-account OpenCode/Devin credentials, but never copies credentials into its observation file or exposes them through a Transport. The existing Codex and native runtimes remain the only writers of their respective credentials. The observer uses bounded provider requests and three-minute paced cycles with jitter, longer retry after failure, and a private atomically replaced measurement file under AgentStack state. A source that has stopped refreshing is marked stale; last-good measurements are not silently presented as current. Provider errors are fixed codes, not upstream bodies or exception text. Account removal prunes its measurement. Grok Bot is explicitly not identified as one of the registered Grok Worker accounts.

AgentUsage's `src/observe.ts` and provider observers informed the provider wire shapes, bounds and pacing, but its separately owned account inventory and balancing decisions are not imported into AgentStack. An expired credential may require the credential owner's native refresh or a new sign-in; usage does not rotate it. The existing canvas discovers the new API generically, while a dedicated usage presentation remains a separate explicit UI request.
