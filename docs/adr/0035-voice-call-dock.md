# 35. A call dock and shared voice state on the canvas

Status: accepted, 2026-09-24. Extends [ADR 0028](0028-main-thread-voice-call.md)'s main-thread voice call and replaces its fixed widget with canvas-wide entry points.

The single voice call is shared state, not a widget. A `VoiceProvider` beside the auth actions provider owns the peer connection, microphone, media, session id, and a generation counter that fences stale async work, the same pattern as [ADR 0026](0026-canvas-auth-controls.md). A Dynamic-Island-style dock appears at the top center only while a call is in progress: the bot tile, phase or elapsed time, live level meters for the local and remote streams (Web Audio analysers, reduced-motion aware), mute, and a round hang-up. When autoplay is blocked it offers "Enable audio"; there is no permanent Play button. A call that `voice_status` reports but this page did not dial — another tab or client — shows "On call elsewhere" with an exact-ID "End call", the recovery path ADR 0028 already documents. Entry points are a phone popover in the top bar listing every bot with its callable reason, a Call button and on-call badge on the bot card, live inspector controls, and palette commands.

Two races shaped the state machine. `voice_dial` marks the call on the server before it returns, so `store.call` re-reads `voice` after a successful dial or hangup instead of waiting for the `voice_changed` notice — the same post-mutation refresh auth mutations use. And the widget could tear down its own fresh call: right after dialing, `voice.data` is still the pre-dial read (null), which looked like "call ended on the bot". The provider therefore only treats a missing or different `voice_status` session as remote-end after it has actually observed its own session id there; until then a lagging refresh is ignored. When the peer connection itself reaches `failed`, the provider calls `voice_hangup` for its session before clearing media — a failed peer is not a hung-up Codex call — and on `pagehide` it fires a best-effort hangup over the open channel so a disappearing browser does not leave a billed realtime session.

Microphone failures get human messages: blocked permission says where to allow it and to dial again, a missing device says no microphone was found. Everything else reports through toasts; the dock carries no persistent error text.
