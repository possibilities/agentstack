# 41. Port the wiki into an isolated Package API

Status: accepted, 2026-09-25. Extends [ADR 0001](0001-package-apis.md)'s typed Package APIs and [ADR 0009](0009-serve-docs-with-owner.md)'s owner-managed lifecycle.

Port agentwiki's plain-file Vault, derived SQLite full-text Index, Git history, ref resolution, document graph, tombstones, content-addressed Artifact manifest and static document/Artifact HTTP routes into `packages/wiki`. Retain the on-disk schemas and URL shapes, and adapt Bun SQLite and HTTP primitives to Node so the Package API runs under the existing owner. The static document and Artifact origins are distinct loopback listeners; a document-origin `/a/…` URL redirects to the Artifact origin, whose CSP limits connections to itself. The owner starts and stops the wiki child alongside the other Package APIs. Socket, MCP and WebSocket expose typed operations; `wiki_status` reports the two actual origins.

AgentStack uses `<AGENTSTACK_STATE_DIR>/wiki/vault` and `<AGENTSTACK_STATE_DIR>/wiki/artifacts`, defaulting to `~/.local/state/agentstack/wiki/…`. Do **not** bind the old `~/wiki` Vault or `~/.local/share/agentwiki` manifest: the original app, its source and its data remain independently usable so selected material can be migrated later. No automatic bulk import, CLI replacement, or restart of either running service is part of this port. AgentStack's Wiki uses ports 8777 and 8778 by default (overridable by `AGENTSTACK_WIKI_PORT` and `AGENTSTACK_WIKI_ARTIFACT_PORT`; zero selects ephemeral ports for tests), avoiding the original app's 7777 and 7778. A future selective migration must copy documents and republish Artifact bytes, not merely copy stub documents without their authoritative manifest and content store.

The original command-only actions `serve`, `mcp`, `open` and `help` are not Package API operations: the shared transports and owner now handle lifecycle, and opening the human's browser is not a server-side wiki mutation. `doctor`, `reindex` and `gc` remain explicit operations. The read-only canvas catalog and `/x.md` show this Package API and its operation schemas, but no dedicated Wiki cards, inspector controls or migration UI are created without a human request.
