# 78. Declare HTTP surfaces and select Package API operations per transport

Status: accepted, 2026-09-26. Extends [ADR 0001](0001-package-apis.md)'s typed Package APIs, [ADR 0008](0008-mcp-rpc-transport.md)'s local control boundary, [ADR 0059](0059-isolated-brain-and-platform-clients.md)'s device ingress, and [ADR 0077](0077-content-collections.md)'s separate static origins.

An `http` declaration in a package's `api.yaml` identifies separately served HTTP surfaces. `api.ts` describes each surface's explicit routes and, for JSON routes, the typed operation and its input/output schemas. The shared `packages/api` HTTP server owns listening, request/response streaming and shutdown; the package retains its own authentication, versioning, route policy and context. HTTP routes are a positive selection, not an alias of the local socket API. Brain's three device-share routes use HTTP-only typed operations that invoke the same Admission ledger as other Brain commands; they are not listed as socket, MCP or WebSocket operations. Content's document and artifact routes configure two separate, read-only origins, retaining the artifact script-isolation boundary and existing URL shapes.

`mcp` and `websocket` manifest entries may additionally name a positive `operations` list. Omission preserves the existing full socket operation set; an empty list exposes none. Both listing and direct invocation enforce the selection. Existing WebSocket connections retain their admission-time selection when configuration changes, as they retain their subscription. MCP checks configuration per request; restricted MCP entries offer no Bot event-subscription tools, so a subscription cannot read an operation outside its selection. Socket remains the owning superset for local inter-package calls. Discovery reports the selected operation names and explicit HTTP routes/schemas without claiming an HTTP listener is live. An `http` declaration requires a socket owner and must match an `api.ts` HTTP surface declaration.

This does not turn the remote-capable device listener into a general REST exposure of Brain controls. Bearer authentication, the version-1 JSON envelope, CORS, idempotency, bounded body and state reads, and the Chrome/Android contract remain unchanged. Content's static views remain unauthenticated and must be exposed deliberately as in ADR 0077. Dynamic listener addresses are reported by package status or registration, not invented by static discovery.
