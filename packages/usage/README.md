# Usage Package API

`usage_snapshot` reads the latest observations for every registered Codex Bot account and every Codex, Devin and Claude Worker account. Each account record has a `scope` (`bot` or `worker`); scope and ID together identify it, including older Bot and Worker Codex accounts that share an ID. `linkedAccounts` repeats auth's pairing of each Codex Bot account with its Codex Worker account, by Stack ID only. It is informational only: measurements are not dispatch authorization. `usage_changed` tells subscribers to read again. IDs match `auth.account_list` for Bots and `auth.worker_account_list` for Workers.

The owner-managed child observes accounts roughly every three minutes (with jitter), retaining the last good data on failures. It reads credentials only from the existing native/account stores and writes **measurements only** to `STACK_STATE_DIR/usage/observations.json` (private mode). It neither owns nor rotates refresh tokens. If the native login expires, expect `auth_unavailable` until its owner refreshes it or the operator signs in again. `observedAtMs` is the last successful sample; `lastAttemptAtMs` and `error` describe the last attempt. `fresh` requires a healthy successful sample no older than five minutes and a current auth inventory.

Devin reads each account's native `credentials.toml`; Codex Workers read their own native OpenCode OAuth credentials; Codex Bots read their Codex auth store. These are deliberately **not** AgentUsage's independent account keys. No balancing, selection, leasing or credential-management operation is exposed here.
