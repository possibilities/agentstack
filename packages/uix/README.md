# UI Experiments

Next.js runtime index at `/` and blank experiment canvas at `/x`, with Tailwind CSS and shadcn/ui. `agentstack serve` owns the built app. For live iteration, run `pnpm --filter @agentstack/uix dev` from the workspace root, edit `app/x/page.tsx`, and add UI primitives from this package with `pnpm dlx shadcn@latest add <component>`.
