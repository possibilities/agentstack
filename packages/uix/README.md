# UI Experiments

Blank Next.js canvas with Tailwind CSS and shadcn/ui. `agentstack serve` owns the built app at its printed UI canvas URL. For live iteration, run `pnpm --filter @agentstack/uix dev` from the workspace root, edit `app/page.tsx`, and add UI primitives from this package with `pnpm dlx shadcn@latest add <component>`.
